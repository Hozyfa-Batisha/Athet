تشغيل موقع أثر على جهازك

1. اضغط مرتين على start.bat من مجلد المشروع.
2. سيفتح الموقع بقاعدة بيانات محلية محفوظة داخل data/athar-local-recovered.
3. الحسابات والتعديلات تبقى محفوظة بعد إغلاق نافذة التشغيل.
4. لإنشاء حساب مدير، أغلق نافذة الموقع أولًا، ثم اضغط مرتين على create-admin.bat من مجلد المشروع.
   اكتب اسم الحساب وكلمة السر (٦ أرقام)، ثم افتح start.bat وسجّل الدخول بنفس البيانات.
   يمكنك أيضًا استخدام: npm run admin:create -- اسم-المدير

هذه قاعدة محلية منفصلة عن قاعدة بيانات الاستضافة. لا تحذف مجلد data إذا أردت الاحتفاظ بحساباتك وتعديلاتك على هذا الجهاز.
حساب المدير المحلي يعمل مع start.bat فقط؛ أمر npm run dev يفتح نسخة تجريبية بقاعدة مؤقتة مختلفة.
