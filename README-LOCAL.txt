تشغيل موقع أثر على جهازك

1. اضغط مرتين على start.bat من مجلد المشروع.
2. سيفتح الموقع بقاعدة بيانات محلية محفوظة داخل data/athar-local-recovered.
3. الحسابات والتعديلات تبقى محفوظة بعد إغلاق نافذة التشغيل.
4. لإنشاء حساب مدير، أغلق نافذة الموقع أولًا، ثم افتح Command Prompt في مجلد المشروع ونفّذ:
   npm run admin:create -- اسم-المدير
   اكتب كلمة المرور واضغط Enter، ثم افتح start.bat وسجّل الدخول.

هذه قاعدة محلية منفصلة عن قاعدة بيانات الاستضافة. لا تحذف مجلد data إذا أردت الاحتفاظ بحساباتك وتعديلاتك على هذا الجهاز.
