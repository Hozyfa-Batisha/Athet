# التغييرات والتحقق

## تغييرات مقصودة

- تقسيم ملف HTML الرئيسي، واستخراج 133 ملف وسائط فريدًا من المحتوى المضمّن دون إعادة ضغطها، والمحافظة على ملفات التسجيلات الأصلية.
- فصل صفحات الألعاب ومحتواها ومواردها، واستبدال محاكاة صفحات `srcdoc` بصفحات حقيقية، مع الإبقاء على روابط الأقسام وتجربة الألعاب.
- تحويل حفظ JSON على القرص وحفظ المتصفح إلى PostgreSQL، وربط كل السجلات بالحساب.
- إلغاء كوكي «تذكرني» الدائمة، والإبقاء على كوكي جلسة HttpOnly مؤقتة.
- التحقق من البيانات وحدود حجم الطلبات، وCSRF، والتحقق من مصدر الطلبات، وحد محاولات الدخول، والتحقق من نوع الصورة، وحماية تقديم الملفات.
- عدم إخفاء أخطاء الحفظ: يظهر فشل الاتصال والتعارض، وتبقى التعديلات غير المحفوظة في ذاكرة الصفحة مع تنبيه قبل مغادرتها.
- ترتيب حفظ الجدول ومنع الكتابة على نسخة أحدث، مع معاملات قاعدة بيانات تمنع الحفظ الجزئي.
- استيراد الحسابات والجداول القديمة مرة واحدة دون تغيير كلمات السر.
- إصلاح مسار الألعاب المختلف في حالة الأحرف بين Windows وLinux.
- تجهيز Docker Compose وملف إعدادات ومثال Nginx ونسخ PostgreSQL الاحتياطي.

## اختبارات التكامل

تغطي الاختبارات:

1. حماية الدخول وتهيئة أول حساب ومنع تكرار اسم المستخدم باختلاف حالة الحروف.
2. استرجاع المجموعات والملاحظات والتواريخ والحقول الإضافية دون فقد.
3. عزل بيانات كل حساب، وإعداداته، وحالة إشعاراته.
4. تعارض تعديلين بنفس revision، ورفض الحفظ القديم.
5. رفض بيانات تالفة، ومعرّفات غير آمنة، وتواريخ غير صحيحة، وتكرار التسجيلات، دون حذف البيانات الحالية.
6. رفض CSRF والمصادر الخارجية وJSON التالف والطلبات الكبيرة.
7. حفظ الملف الشخصي ورفض صور SVG وتغيير كلمة السر وإغلاق الجلسات الأخرى.
8. تصدير الحساب دون hashes كلمات السر أو مفاتيح الجلسات.
9. حماية الملفات الخاصة، ودعم Range للصوت، وتعطيل تخزين الاستجابات الخاصة عبر `Cache-Control: no-store`.
10. استمرار البيانات والجلسات بعد إعادة تشغيل خادم HTTP.
11. إنهاء الجلسة الحالية فقط عند الخروج.
12. استيراد القديم داخل transaction والتراجع عند تلفه ومنع تكرار الاستيراد.
13. تحديد محاولات الدخول.
14. استمرار السجلات بعد إغلاق محرك قاعدة البيانات وإعادة فتحه من القرص.

تستخدم الاختبارات PGlite ببيانات وهمية؛ لا تستخدم حساباتك الفعلية لتغيير كلمة سر أو حذف بيانات. جرى أيضًا اختبار استيراد بيانات الملف المرفوع إلى قاعدة مؤقتة: حسابان و16 تسجيلًا. لم تتغير ملفاتك الأصلية.

`npm run check` يفحص صياغة JavaScript والمراجع المحلية وغياب مخازن بيانات المتصفح في كود الواجهة. لا يوجد تضمين لجلسات قديمة أو مفاتيح بوت في الأرشيف الجديد.

## نطاق التحقق

Docker/PostgreSQL الفعليان وإعداد الدومين وHTTPS يحتاجان التشغيل على استضافتك. لم يتم نشر موقع أو تشغيل خدمة خارجية أو إرسال نسخة إلى تيليجرام. لا توجد بيانات حسابات تجريبية داخل نسخة الإنتاج.

## مراجعة الواجهة

نجحت تجربة تسجيل حصة في الواجهة ثم إعادة تحميلها، وتغيير المظهر، والتنقل بين بوابة الألعاب ولعبة الحروف، وإكمال نشاط ترتيب الآيات ثم إعادة تحميل الصفحة والتحقق من بقاء النجوم. راجعت أيضًا عرض القرآن وبطاقات الحروف والسبورة.

تطابقت 139 قيمة ID و98 معالج أحداث و412 خاصية class في الصفحة الرئيسية مع الأصل، بعد تجاهل المسافات غير المؤثرة في class. حُفظت قواعد media queries الأصلية: 23 في الموقع، و38 في بوابة الألعاب، و8 في صفحة لعبة الحروف. ملفات الوسائط المستخرجة مطابقة لبايتات المصدر.

جرت مراجعة قواعد الهاتف عند عرض CSS مقداره 539 و337 بكسل عبر تكبير المتصفح، بجانب عرض سطح المكتب. هذا فحص للتخطيط المتجاوب؛ لم يُجر اختبار على هاتف فعلي أو اختبار شامل لكل جولات الألعاب.
