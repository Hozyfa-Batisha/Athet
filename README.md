# أثر - نظام الحصص والطلاب

تطبيق ويب بسيط لإدارة حصص الطلاب، يشمل جدول الحصص، وتسجيل الطلاب، وحصاد الشهر، وقسم تعليمي للألعاب، وعرض القرآن الكريم، وسبورة تفاعلية.

## المميزات

- **الجدول:** عرض حصص اليوم والأسبوع، مع الساعة والتقويم الهجري والميلادي.
- **سجل الطلاب:** تسجيل الطلاب مع اليوم والحصة والتوقيت والملاحظات.
- **تسجيل العائلات / المجموعات:** تسجيل أكثر من طالب باسم واحد، ويُحسب كحصة واحدة بساعاتها الطبيعية.
- **حصاد الشهر:** ملخص لعدد الحصص والساعات لكل طالب خلال الشهر.
- **العب و تعلم:** مكتبة من ألعاب تعليمية للشدّة والحروف والحركات والمدود، تعمل داخل الصفحة.
- **القرآن الكريم:** عرض الآيات مقسّمة حسب الأجزاء (27 و28 و29 و30)، مع تلاوة صوتية لكل آية.
- **السبورة التفاعلية:** لوح عرض داخل الموقع.
- **الوضع الفاتح والداكن:** تبديل بين المظهرين من زر في الترويسة.

## هيكل المشروع

```
athar/
├── index.html        # الصفحة الرئيسية (تشمل الأنماط والسكربت والشعار)
├── logo.png          # الشعار باللون الذهبي (للوضع الداكن)
├── logo-green.png    # الشعار باللون الأخضر (للوضع الفاتح)
└── games/            # ملفات الألعاب التعليمية
    ├── shidda-rihla.html
    ├── shidda-fuqaah.html
    ├── harf-museum.html
    ├── harf-sayd.html
    ├── qitar-harakat.html
    ├── mutabaqa-harf.html
    ├── bustan-mudood.html
    └── muhandis-kalimat.html
```

الشعار مضمّن داخل `index.html`، فملفات الشعار ليست ضرورية للتشغيل.

## التشغيل

لا يحتاج المشروع تثبيت أي شيء. افتح ملف `index.html` في المتصفح مباشرة، أو استخدم أي خادم ثابت، مثلاً:

```bash
npx serve .
```

ملاحظة: بعض الألعاب والتصميم يعتمدون على مكتبات من الإنترنت (Tailwind وFontAwesome وTone.js وGoogle Fonts)، فتحتاج اتصال بالإنترنت لتظهر الشكل كامل.

## حفظ البيانات

تُحفظ بيانات الطلاب والحصص في **المتصفح نفسه** (localStorage). يعني إذا فتحت الموقع من متصفح أو جهاز ثاني، ما راح تلقى نفس البيانات.
